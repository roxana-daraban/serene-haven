# Serene Haven — Frontend

Aplicația web React pentru Serene Haven. Documentația completă este în [**README-ul din rădăcină**](../README.md).

## Structură sursă (rezumat)

```
src/
├── App.tsx              # Layout: Navbar, Routes, Footer, ScrollToTop
├── components/          # Navbar, Footer, ScrollToTop
├── pages/
│   ├── LandingPage/
│   ├── Services/
│   └── Contact/
└── main.tsx
```

## Comenzi

```bash
npm install
npm run dev      # development (http://localhost:5173)
npm run build    # producție → dist/
npm run lint
npm run preview  # previzualizare build
```
